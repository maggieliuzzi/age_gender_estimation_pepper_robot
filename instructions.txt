If you want to write your own tests, here is the parameters...
-source = The root directory of the dataset you're copying images from (generally where wiki.mat is located); required, but ignored if -nop is set
-destination = The directory where the preprocessed images will be copied to AND where Keras will find them for training; always required
-facescore = Minimum score required for an image to be 'kept' for training. Default is 2. Almost all images scored 0-7. Non-faces are mainly 0-1
-sampling = The type of resampling to apply during preprocessing. Can be "" (for none), "up" (for upsampling) or "down" (for downsampling)
-model = Which Keras model to use as the base model for the network. Currently works with "MobileNetV2", "InceptionV3" and "DenseNet121". "RasNetMobile" is also available, but doesn't work with Theano.
-pooling = Which type of pooling the top-most layer of the base network uses. Keras supports "avg", "max" or "none". Average is the default
-retrain = The number of layers of the network to leave unfrozen, allowing them to be retrained. Defualts are 4 for MobileNetV2, 32 for InceptionV3 and 45 for densenet121
-batchsize = Batch size during training - that is, the number of images to load into memory at a time. Default is 20. Lower this if you get memory errors
-valsize = Batch size during validation. Default is 10. Lower this if you get memory errors
-epochs = The number of full runs of the dataset (called an 'epoch') to perform during training. Default is 10
-mname = The name of the .h5 file that is output. Intermediates at the end of each epoch will be <name>.<epoch>.h5
-noprocess = A flag; if set, preprocessing is skipped. Use this if you're running a different model on an already preprocessed dataset (as seen in the examples above)
-nofilter = A flag; if set, preprocessing won't apply the "pepperizer" filter to the images, leaving them in high quality
-notrain = A flag; if set, Keras will not perform any retraining before saving the model
